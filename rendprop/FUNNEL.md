# Rendprop Hosts — Funnel

**The persona is traffic. The install is the business.** Every reel points at one measurable action.

## The CTA

Replace "Explore Rendprop at rendprop dot com" (unmeasurable, and a website CTA for an iOS app) with a **comment keyword**:

> "Comment **TOUR** and I'll send you the app."

Keyword per pillar, so we can read demand by topic:

| Pillar | Keyword | DM link |
|---|---|---|
| Walkthrough → tour reveals | TOUR | App Store link `?ct=ig-tour` |
| AI Photo Studio / staging | STAGE | `?ct=ig-stage` |
| Photos → reel | REEL | `?ct=ig-reel` |
| Restaurants / gyms / venues | SPACE | `?ct=ig-space` |

Append the host to the token when both hosts cover the same pillar: `ct=ig-tour-ava` / `ct=ig-tour-mia`. The `ct=` campaign tokens already exist on Rendprop's store links; this just gives each reel its own.

## The DM

Automation (ManyChat or the pilk-ai GHL sub-account — whichever is already wired to the Rendprop IG):

1. Trigger: comment contains the keyword on any post.
2. Public reply: "Sent you a DM 📩" (short, human, no exclamation pile-up).
3. DM 1 (instant): "Here's Rendprop — film a walkthrough on your phone, get a tour you can share: {App Store link with ct token}. If you're not on iPhone yet, reply ANDROID and I'll let you know the second it's out."
4. DM 2 (24 h later, only if no install event): one real tour link to look at — a published tour page, not a promo.
5. Tag the contact with the keyword so the list is segmented from day one.

## Bio

"Ava & Mia, Rendprop's AI hosts. Phone walkthrough → cinematic tour. AI-generated characters."
Link: rendprop.com (the site handles the App Store handoff with its own `ct=site` token).

## Disclosure (non-negotiable)

- Instagram "AI-generated profile" label on.
- On-screen "· Rendprop AI host" ID in every reel.
- Caption line every time: "Ava is an AI-generated host." / "Mia is an AI-generated host."

## What to read weekly

- App Store Connect → campaign tokens: installs per `ct=` value. This is the scoreboard.
- Comments per keyword → which pillar people actually want.
- DM list size by tag.
- Reel retention curve at 0–3 s (is the hook b-roll working?) and at the demo cutaway (are people leaving when the product shows up, or staying?).
